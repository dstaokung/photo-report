# เอกสารภาพถ่ายประกอบการส่งงานก่อสร้าง (Photo Report Builder)

เว็บแอปไฟล์เดียว (`index.html`) ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ส่งรูปขึ้นอินเทอร์เน็ต

## ความสามารถ
- หัวกระดาษ: ชื่อเอกสาร / ชื่อโครงการ / สถานที่ / สัญญาเลขที่ / ผู้รับจ้าง / งวดงาน (แสดงทุกหน้า)
- 4 หมวดเริ่มต้น: รูปก่อนดำเนินการ, รูประหว่างดำเนินการ, รูปดำเนินการแล้วเสร็จ, รูปการตรวจรับพัสดุ
  (แก้ชื่อหมวดได้ เพิ่มหมวดใหม่ได้ ลบหมวดได้)
- อัพโหลดรูปหลายไฟล์พร้อมกัน หรือลากไฟล์มาวาง (ย่อรูปอัตโนมัติด้านยาว 1600 px)
- จัดลำดับรูป: ลากรูปย่อสลับตำแหน่ง / ลากข้ามหมวด / ปุ่ม ◀ ▶ บนหน้ากระดาษ / เรียงตามชื่อไฟล์ หรือเวลาไฟล์ / กลับลำดับ
- หมุนรูป 90° ต่อครั้ง (ปุ่ม ↻ บนรูปย่อหรือบนหน้ากระดาษ) — หมุนที่ตัวรูปจริง ค่าที่หมุนติดไปกับไฟล์โปรเจกต์และงานพิมพ์
- คำบรรยายใต้รูป: คลิกพิมพ์บนหน้ากระดาษได้เลย
- ลายเซ็น: คณะกรรมการ 0–5 ท่าน + ผู้ควบคุมงาน 0–2 ท่าน (เลือก "ไม่มี" ได้ทั้งสองช่อง / เว้นชื่อว่าง = เส้นประให้เซ็นมือ)
- ตำแหน่งลายเซ็นเลือกได้: **ท้ายทุกหน้า** (ค่าเริ่มต้น) / ไม่มีลายเซ็น / หน้าลายเซ็นท้ายเอกสารหน้าเดียว / ทั้งสองแบบ
  แถบท้ายหน้าเป็นแบบ 1 คน 1 บรรทัด: ชื่อ (ตำแหน่ง) แล้วตามด้วยเส้นลงชื่อ
- รูปแบบหน้า: 1 / 2 / 4 / 6 รูปต่อหน้า, ขนาดรูป (ใหญ่/กลาง/เล็ก), ขนาดตัวอักษร (มาตรฐาน/เล็ก/เล็กมาก),
  พอดีกรอบหรือเต็มกรอบ, เปิด-ปิดคำบรรยาย เลขรูป เลขหน้า
- ย่อรูป/ตัวอักษรอัตโนมัติเมื่อเนื้อหาล้นหน้า (เช่นชื่อโครงการยาวหลายบรรทัด) เพื่อให้จบใน 1 หน้าเสมอ
- พิมพ์ A4 แนวตั้ง หรือ Save as PDF จากหน้าต่างพิมพ์ของเบราว์เซอร์
- บันทึก/เปิดไฟล์โปรเจกต์ `.json` (เก็บรูปและข้อความทั้งหมด) เพื่อกลับมาแก้ทีหลัง

## วิธีใช้แบบออฟไลน์
ดับเบิลคลิก `index.html` เปิดด้วย Chrome หรือ Edge ได้เลย

## วิธีขึ้น GitHub Pages (ไม่ต้องใช้ command line)
1. ล็อกอิน github.com → ปุ่ม **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ เช่น `photo-report` → เลือก **Public** → **Create repository**
3. หน้าถัดมากด **uploading an existing file** → ลากไฟล์ `index.html` (และ `README.md`) มาวาง → **Commit changes**
4. เข้าแท็บ **Settings** → เมนูซ้าย **Pages** → หัวข้อ *Build and deployment* → Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**
5. รอ 1–2 นาที แล้วรีเฟรช จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/photo-report/`

อัพเดตโปรแกรมภายหลัง: อัพโหลดไฟล์ `index.html` ทับของเดิมใน repo

## หมายเหตุการพิมพ์
ในหน้าต่างพิมพ์ของ Chrome ให้ตั้ง **ขนาดกระดาษ A4**, **ระยะขอบ = ไม่มี (None)**, และเปิด **กราฟิกพื้นหลัง** เพื่อให้ตรงกับที่เห็นบนจอ

## ความเป็นส่วนตัว
รูปทั้งหมดอยู่ในหน่วยความจำของเบราว์เซอร์เครื่องที่ใช้เท่านั้น ไม่มีการอัพโหลดออกนอกเครื่อง
ถ้าปิดแท็บโดยไม่ได้กด "บันทึกโปรเจกต์" ข้อมูลจะหาย
